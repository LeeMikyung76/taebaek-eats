# 태백 맛집 지도 (taebaek-eats)

태백의 식당 11곳과 카페 3곳을 지도와 목록으로 보는 한 페이지짜리 웹 앱입니다.
빌드 도구 없이 `index.html` 한 파일(HTML + CSS + JS)로 되어 있어요.

- 지도: [Leaflet](https://leafletjs.com/) 1.9.4 + [OpenStreetMap](https://www.openstreetmap.org/copyright) 타일
- 배포: Vercel (GitHub `main` 브랜치에 push하면 자동 재배포)

## 사용법

| 동작 | 결과 |
|---|---|
| 목록 항목 클릭 (또는 Tab으로 이동 후 Enter) | 위치·영업시간·휴무일·전화·지도 링크가 펼쳐지고, 지도가 그 가게로 이동하며 마커가 강조돼요. 다시 누르면 닫혀요. |
| 지도 마커 클릭 (또는 포커스 후 Enter) | 위와 같고, 목록이 그 가게로 스크롤돼요. |
| 전체 / 식사 / 카페 | 구분별로 걸러요. |
| 오늘 쉬는 곳 빼기 | 오늘(한국 시간 기준)이 휴무일인 가게를 숨겨요. |

목록에서 빠진 가게는 지도 마커도 함께 숨겨져요. 라이트/다크 모드는 기기 설정을 따라가요.

### 로컬에서 보기

`index.html`을 더블클릭해서 브라우저로 열면 됩니다. (지도 타일과 Leaflet은 인터넷에서 불러와요.)

## 가게 추가·수정하기

`index.html` 안의 `PLACES` 배열에서 한 줄이 가게 하나예요. 목록 번호는 배열 순서대로 자동으로 붙고,
제목 아래 "식당 N곳 · 카페 N곳"도 자동으로 계산돼요.

```js
{ name:"가게 이름", tag:"한식", type:"식사", where:"황지동", menu:"한 줄 메뉴 설명", hours:"매일 11:00–21:00", closed:[1], tel:"033-000-0000", lat:37.16, lng:128.98, cid:"" },
```

| 항목 | 설명 |
|---|---|
| `name` | 가게 이름 (네이버·카카오·구글 지도 링크에도 쓰여요) |
| `tag` | 분류 태그 (예: 한식, 칼국수, 카페·베이커리) |
| `type` | `"식사"` 또는 `"카페"` — 마커 색이 달라져요 (식사 초록, 카페 갈색) |
| `where` | 위치 설명 |
| `menu` | 목록에 보이는 한 줄 메뉴 설명 |
| `hours` | 영업시간. 모르면 `""` → "정보 없음" |
| `closed` | 휴무 요일 배열. `0`=일 `1`=월 … `6`=토. 휴무 없으면 `[]`(연중무휴), 모르면 `null` |
| `tel` | 전화번호. 모르면 `""` |
| `lat`, `lng` | 위도, 경도 |
| `cid` | 구글 지도 cid. **큰 숫자라 꼭 따옴표로** 감싸 주세요. 모르면 `""` → 이름으로 검색 |

### 위도·경도 찾는 법

구글 지도에서 가게 위치를 **마우스 오른쪽 클릭** → 맨 위의 숫자(예: `37.1763, 128.9868`)를 누르면 복사돼요. 앞이 위도, 뒤가 경도예요.

### 지도 링크 규칙

- 네이버: `https://map.naver.com/p/search/태백 {이름}`
- 카카오: `https://map.kakao.com/link/map/{이름},{위도},{경도}`
- 구글: cid가 있으면 `https://maps.google.com/?cid={cid}`, 없으면 `태백 {이름}`으로 검색

## 배포

```bash
git add index.html
git commit -m "가게 추가: ○○○"
git push
```

push하면 Vercel이 자동으로 다시 배포해요. 보통 수십 초 안에 사이트에 반영돼요.
